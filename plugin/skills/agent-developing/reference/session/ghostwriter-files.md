# Ghostwriter files and commands

Read before materializing, editing, linting, or pushing no-code resources. Follow [ghostwriter](ghostwriter.md) for the edit and concurrency safeguards. The forms below match SDK 0.20260813; confirm them with `pnpm sierra ghostwriter --help` before use.

Run `pnpm sierra ghostwriter <subcommand>` from `agents/{agent}`, one subcommand per invocation.

- `init [name]` binds the directory to that Agent Studio target, signs in, mints the workspace credential, and downloads `.composer/`. Later subcommands take no workspace positional.
- `pull` downloads the current content and refreshes the bundled docs and skills. It backs up the existing local files to a timestamped directory under `.composer/history/working/` and the pulled server state under `.composer/history/synced/`, and needs no confirmation flag. Recover an overwritten local edit from `history/working`.
- `lint [paths..]` performs local validation and a server-side dry run. Paths select the resources that contain those files.
- `push` lints, then publishes the complete local copy, not a delta. `--yes` skips the confirmation prompt, `--skip-lints` skips the lint pass, and `--replace` replaces server content instead of merging; read its `--help` text before using either of the last two. Deleting a local block file deletes that block on push.
- `restore [paths..] --workspace-version-id <id>` restores files from a prior workspace version. It is a recovery operation; lint and push the restored changes when ready.
- `generate types` regenerates the typed `implementation.ts` wrappers after a change to a tool's `definition.json`.
- `token mint <org>` and `workspace <command>` serve headless use; read [ghostwriter credentials](ghostwriter-auth.md).
- `configure mcp` writes the MCP client configuration for the project; [MCP connection](mcp-connection.md) covers the connection itself.

Do not assign `$uuid` values to new blocks. Lint assigns identities and renames their files.

`.composer/` is an ephemeral, gitignored working copy; the server is authoritative. Pull before editing, keep the pull-to-push interval short, and inspect deletions and concurrent changes before publishing. Git conflict markers left in a block file break the readers that walk `.composer/`; resolve them first.

## Downloading evidence

The download flags are hidden from `--help`. Their current forms and the on-disk layout are in `.composer/docs/agent-traces-reference.md`, regenerated by `pull`; pass the full-domain target after `ghostwriter` when the agent has more than one workspace. Skip a download when the directory's `SYNCED_AT` marker exists. Read [result access](../gates/simulation-results.md) before reading them.
